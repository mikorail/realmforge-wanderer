# Realmforge Wanderer

Caves-of-Qud-style ASCII roguelike played across worlds made in Realmforge (`../realmforge`). Separate app: Realmforge only exports world files (Export dialog → "Wanderer World", or `npx tsx scripts/adventure-world.ts` there); this game loads them. No LLM/AI-model API calls.

## Stack
- Go 1.23, no deps (module `wanderer`): `engine/` is the whole game and draws a 112×34 character grid; `cmd/wasm` exposes `window.qud` (`palette`, `init(worldJSON)` → chargen options, `newGame(spec)`, `load(save)`, `key(k)`, `save()`, `meta()`, `deeds()`).
- Web shell: Vite 8 + Svelte 5 runes (no SvelteKit), `fflate`, Share Tech Mono. `src/App.svelte` (title: continue runs, bundled sample worlds, load a Realmforge .json), `CharGen.svelte` (species → calling → point-buy → genre-named powers/defects → origin; rules mirror `engine/chargen.go`), `Play.svelte` (canvas grid, keys incl. numpad, click-to-walk, autosave every 150 keys), `qud.ts` (wasm loader), `store.ts` (IndexedDB `realmforge-wanderer`: meta/save/world per world seed, deflated).

## Run
- System node is too old: npm scripts go through `scripts/run-with-nvm.sh`. Dev: `scripts/dev.sh` (port **5195**), preview config "realmforge-wanderer" in `claude-projects/.claude/launch.json`.
- `npm run wasm` rebuilds `public/wasm/qud.wasm` + `wasm_exec.js` (Go ≥1.24 keeps it in `lib/wasm`, older in `misc/wasm`; it must match the compiler) after any Go change (reload the page; the engine is cached on `window.qud`). `npm run build` = wasm + vite build.
- `public/worlds/` holds bundled sample worlds + `index.json` (regenerate from Realmforge: `npx tsx scripts/adventure-world.ts <years> <genre> <seed> <template>`).
- Tests: `go test ./engine/` (scenario tests against the bundled worlds: combat, death, ritual, quests, trade, sky falls, breath, powers, stairs, travel, save/load, every species × calling).
- Dev tools: `go run ./cmd/fuzz world.json [steps]` (random keys, zone warps, save/load round trips: run after engine changes); `go run ./cmd/peek world.json talk show key:c show down show` prints screens as text.

## Engine map (`engine/`)
`world.go` WorldData schema (must match Realmforge `src/lib/adventure/export.ts`) · `genre.go` per-genre `Skin` (callings, power names, materials, gear, ritual, currency) · `zone.go` 80×25 zones, 3×3 per parasang; z>0 strata and Realmforge deep layers, z=−1 sky isles, sea floor; towns with the sim's notables, ruins with chronicle inscriptions, crypts of dead rulers holding their relics, wonders, sim-monster lairs · `terrain.go` · `creatures.go` · `items.go` · `entity.go` (body plans, limbs) · `combat.go` (d20+AGI vs DV, up to 3 penetration rolls PV vs AV chaining, dismember/bleed/stun, elements, fire) · `ai.go` (shadowcast FOV, light/darkvision, BFS pursuit) · `faction.go` (rep per realm/faith/creature faction from home realm relations and wars; NPC generation) · `talk.go` (ritual → rep + secret from history, gossip from real events, trade, quests, ferries, lore books) · `powers.go` · `input.go` · `render.go` · `game.go` (turn/energy loop, survival, world map, save/load, deeds, `MusicState` for the soundtrack).
- `city.go`: towns ranked by a size score (`WorldData.cityTier`, top 8% → 3×3 great cities, next 25% → 5 zones); each zone is a district picked from the town's real economic sectors (market, harbor, temple + graveyard of real dead, academy, barracks, arena, forge, artisans, mines, farms, slums, homes, palace/plaza), walls/gates on edges facing open country. `landmarks.go`: palaces named after the ruling house, clock/bell/pagoda towers, bridges over rivers, universities, colosseums, columns of real dead rulers, lighthouses, cathedrals… often holding a unique item.
- `dungeon.go`: one deterministic `siteAt` registry (ruin catacombs, temple catacombs, mines, thieves' warrens, Realmforge outlaw hideouts, tower wonders, the Spire of Trials and Bottomless Abyss — placed by `WorldData.placeMegas` when the world file has none — plus seeded wilderness dungeons/towers). Dungeon levels are z>0 under the entrance zone; tower floors are z = −100−floor (`towerStair` keeps consecutive floors' stairs aligned). Themes, bosses, locked vaults + keys, hidden traps (`s` searches), ore.
- `cooking.go`: `C` cooks at a campfire / town hearth (no hostiles in sight, not in water). Ingredients (`Kind "ingredient"`, or a beast corpse; `Item.Effect` = one of 10 tags: hearty spry thick mending keen ember rime deep lasting venom) come from kills (`corpseTag`: flags fire/frost/aquatic/fly/…; people and undead give none), wild herbs and cave fungi (`scatterHerbs`, side rng `seed:herbs:zoneKey`, so zone generation is unchanged) and merchants' local staples parsed from `CultureData.Food` (`staples`/`stapleTag`). 2 ingredients (3 at Survival 2) → `Actor.Meal` tag→level (max 2) for `Game.MealLeft` minutes (1440 + 360 × Survival, +25% for a known dish); hooks in `Score`/`AV`/`DV`, regen, `breathCap`, `hurt` (`resistMeal`), `onHit` (venom), hunger (`slowHunger`). New combos go into `Game.Cookbook`, named after the local culture; journal tab 4. `applyMeal` shares a cooked meal with companions in the zone (`Actor.Meal` + `fed` status, cleared when it expires). Merchants also sell a culture's signature `dish` (`localDish`: two staples, deterministic per culture) that gives a meal without a fire. Kin (after the ritual) offer "Swap recipes" once (`fl recipes`): they teach their dish, you teach one from another land for reputation. Tests: `cooking_test.go`.
- Agent-built systems: `rarity.go` (common→unique tiers, biblical/occult/omni/… categories, boss drops), `powers2.go` (swimming, diving, climbing, clipping, spells, clairvoyance, time dilation, force bubble, fugue, multiple arms…), `inventory.go` (weight, backpacks, encumbrance, tabbed sorted inventory with compare), `attire.go` (regional clothes per sphere, tailors, transmog, attire affinity), `checks.go` (Disco/Fallout skill checks + inner voices), `society.go` (strata per sphere/doctrine/ideology/genre, households, kin, caste prices/greetings). Web: `src/music.ts` (procedural adaptive chiptune from `frame.music`), `src/settings.ts` + `Settings.svelte` (⚙ / backquote).
