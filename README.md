# Realmforge Wanderer

An ASCII roguelike in the spirit of Caves of Qud, played across worlds forged and simulated in [Realmforge](../realmforge): their realms, faiths, species, underground layers, sky isles, monsters, relics and centuries of chronicle.

```sh
npm install
npm run wasm      # needs Go 1.23+
scripts/dev.sh    # http://localhost:5195
```

Play a bundled world, or in Realmforge open Export → **Wanderer World** and load the downloaded `.json` here.
